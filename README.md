# FrameForge v2

A Figma-style website layout designer. Frontend: HTML, CSS and vanilla JS. Backend: Python (Flask + SQLite).

Features: auto layout (flex/grid), gradients, multiple fills/strokes/effects, image upload, extra shapes and form controls, text styling with Google Fonts, groups, alignment, rulers/guides/grid, components and instances, colour and text styles, block and page-template library, multiple pages, prototype/present mode, export to HTML, HTML+CSS, React, Tailwind, Bootstrap, PNG, SVG and PDF, publish link, light/dark theme, context menu, minimap, layer search and touch support.

See `static/user_guide.html` (also linked from the editor as "User Manual") for the full guide.

Layout: `app.py` (routes), `exporter.py` (code generation), `icons.py`, `templates/index.html`, `static/style.css`, `static/js/*.js`.
