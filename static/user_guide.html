1Getting started

The first launch loads a demo landing page with desktop and mobile frames. Select its layers to see how it is built. To start empty, click New.

  • Top bar: project name, undo/redo, New, Open, Import, Export JSON, Preview, Export HTML, Save.
  • Left panel: the Layers list.
  • Centre: the canvas, with the tool palette at the bottom and zoom controls at the bottom right.
  • Right panel: Design properties for the selected layer.

4Selecting and moving

  • Click a layer to select it. Shift+click adds or removes layers from the selection.
  • Drag to move. Red guides appear when edges or centres line up with neighbours. Hold Alt to turn snapping off. Hold Shift to lock movement to one axis.
  • Drag the 8 handles to resize. Shift with a corner handle keeps the proportions.
  • Arrow keys nudge by 1px. Shift+arrow nudges by 10px.
  • Drag a layer out of one frame and into another to re-parent it.
  • Double-click text or a button (or press Enter) to edit it. Press Esc or Ctrl+Enter to finish.

5Layers panel

  • Double-click a name to rename it.
  • The 🔒 and 👁 icons lock and hide a layer. Locked layers can't be selected on the canvas. Hidden layers are left out of the export.
  • Children are indented under their frame. Layers higher in the list sit on top.

6Properties panel

  • Position: X, Y, W, H are relative to the parent frame. Children also get align buttons (left, centre, right, top, middle, bottom).
  • Text and Button: content, size, weight, font (Inter, Georgia, Mono), alignment, colour.
  • Appearance: fill (or No fill), corner radius, opacity, drop shadow. Frames also have Clip content.
  • Stroke: colour and width.
  • Order buttons: bring to front, forward, backward, send to back. Shortcuts: ], [, Ctrl+], Ctrl+[.

7Saving and loading

  • Save (or Ctrl+S) stores the project in the local database. After the first save, changes auto-save about 1.5 seconds after you stop editing. The status label next to the name shows Unsaved, Saving… or Saved.
  • Open lists your projects, newest first. Click one to load it. The 🗑 icon deletes it.
  • The app reopens your last project on reload.
  • Export JSON and Import move designs between machines as .json files.

8Exporting to HTML/CSS

  • Preview opens the generated page in a new tab.
  • Export HTML downloads a standalone .html file with inline CSS and no dependencies.
  • Each top-level frame becomes a <section>, text becomes <div>, buttons become <button>, and images become <img>.
  • The export uses absolute positioning, so it looks exactly like the canvas but won't reflow on other screen sizes. Make one frame per breakpoint (the demo has desktop and mobile).
  • Images need a public URL (https://…) to appear in the export.

10Troubleshooting

  • Can't select something: it may be locked. Check the 🔒 in Layers.
  • Layer vanished: it may be hidden. Check the 👁 icon.
  • Image is blank: paste a full https:// image URL in the properties panel.
  • Data location: projects live in designs.db next to app.py. Delete that file to reset everything.
