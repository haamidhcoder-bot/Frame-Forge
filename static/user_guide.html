1Getting started

The editor has a top bar (file, edit, view, export, publish), a left panel (Pages and Layers), the canvas in the middle with a toolbar, and a Properties panel on the right. A demo document with a desktop and a mobile landing page is loaded the first time.

  • Work is organised into pages; each page holds any number of frames (artboards).
  • Press Ctrl+S or Save to store the design on the server; unsaved changes are lost if you close the tab.
  • Press ? in the top bar at any time for the shortcut cheat-sheet.

2Navigating the canvas

  • Pan: hold Space and drag, use the Hand tool (H), or the middle mouse button.
  • Zoom: Ctrl+scroll, pinch on a touch screen, or the zoom bar. Shift+1 fits everything, Shift+2 fits the selection, Ctrl+0 returns to 100%.
  • Minimap: the small overview in the corner; click it to jump to that area.

3Drawing and elements

Pick a tool from the toolbar (or press its key) and drag on the canvas. Click without dragging to drop a default-sized element.

4Selecting, grouping and aligning

  • Click to select; Shift+click to add; drag on empty canvas for a marquee. Ctrl+A selects all on the page.
  • Drag to move, drag handles to resize. Shift constrains, Alt turns snapping off. Arrow keys nudge (Shift = 10 px).
  • Group Ctrl+G, Ungroup Ctrl+Shift+G.
  • Align left/centre/right/top/middle/bottom and distribute horizontally or vertically from the Properties panel when two or more layers (three for distribute) are selected. Alignment is relative to the selection, or to the parent frame for a single layer.
  • Ctrl+C / X / V, Ctrl+D duplicate, Del delete, [ ] change stacking order.
  • Undo and redo are unlimited within the session: Ctrl+Z, Ctrl+Shift+Z.

5Pages and layers

  • Pages (top of the left panel): add, rename, duplicate or delete pages. Each page has its own set of frames.
  • Layers: a tree of everything on the page. Click to select, drag to reorder or re-parent, use the eye and lock icons, double-click to rename.
  • Search: type in the search box above the tree to filter layers by name.

6Properties: fills, strokes, effects, text

  • Position and size: X, Y, W, H, rotation and corner radius.
  • Fills: any number of fills per layer. Each is a solid colour, a linear gradient (with angle) or a radial gradient, with its own opacity. Fills stack top-down.
  • Strokes: any number of strokes, each with its own colour and width. Extra strokes render as concentric rings.
  • Effects: drop shadow, inner shadow, layer blur and background blur, each with its own controls.
  • Text: font family (Google Fonts), weight, size, line height, letter spacing, alignment, italic, underline and strikethrough.
  • Opacity and visibility apply to the whole layer.
Colours can be bound to a colour style; text can be bound to a text style. See Colour and text styles.

7Auto layout

Select a frame (or a group) and press Shift+A to turn on auto layout. The frame then arranges its children like CSS flexbox or grid, and the export uses real display:flex / display:grid.

  • Direction: row, column or grid (with a column count).
  • Gap, padding, wrap, alignment and justify control spacing and distribution.
  • Child sizing: each child can be Fixed, Fill (take the remaining space) or Hug (shrink to content).
  • Drag a child inside an auto-layout frame to reorder it; a drop indicator shows where it will land. Hold Ctrl while hovering a sibling container to drop into it instead.
  • Shift+A again removes auto layout and children keep their current positions.

8Images and icons

  • Upload: choose the Image tool and click, then pick a file; or drag an image file onto the canvas; or paste an image from the clipboard. Uploaded images are embedded in the design.
  • Fit mode: cover, contain or fill in Properties.
  • Icons: click the star button in the toolbar (or press K), pick an icon, then click or drag on the canvas to place it (the Library also has an Icons tab); colour and size follow the stroke colour and the layer size.

9Components and instances

  • Select a layer and press Ctrl+Alt+K to turn it into a component (master).
  • Insert instances from the Library (right-click › Go to main component jumps to the master). Edit the master and every instance updates.
  • Inside an instance you can override text, fills and visibility without changing the master.
  • Ctrl+Alt+B detaches an instance into ordinary layers.
  • Component masters are not included in exports.

10Colour and text styles

Open Styles in the top bar.

  • Colour styles: name a colour once and bind fills and strokes to it. Editing the style recolours everything that uses it, in the editor and in exports.
  • Text styles: save font, size, weight, line height and letter spacing as a named style; apply it from a text layer's Properties.

11Library: blocks and page templates

Open Library in the top bar.

  • Blocks: ready-made sections such as navbar, hero, feature grid, pricing, testimonial, footer and form controls. Click to insert at the centre of the view, or into the selected frame.
  • Page templates: full landing, mobile and other pages that you can add to the current page.
  • Components: all components in the document, ready to insert as instances.

12Rulers, guides, grid and minimap

  • View ▾ toggles rulers (Shift+R), the pixel grid (Ctrl+'), snapping and the minimap.
  • Drag from a ruler to create a guide; drag it back onto the ruler to remove it. Elements snap to guides.

13Prototype and Present mode

  • Select a button or any layer and, under Link in Properties, choose a target frame or enter a URL.
  • Press ▶ Present to view the design full screen. Clicking linked layers navigates between frames. Esc exits; a back control returns to the previous frame.
  • The same links work in the exported HTML.
  • Flow arrows: every layer that has a link shows an orange outline and an arrow to its target, with a label such as Sign up → Landing – Mobile. Solid arrows go to frames; dashed arrows go to an external URL box or to a frame on another page. Click a label to jump to the target; use Go to target in the Interaction section for the same. A layer whose link has no target shows no target.
  • Turn arrows off or limit them to the selected layers under View ▾ › Show flow arrows / Only for selected. They appear only in the editor, not in exports.

14Saving and loading

  • Save stores the design in the server database; Open lists saved designs to load or delete. The last design you worked on reopens automatically.
  • New starts a blank document. Import loads a .json design file; Export › JSON downloads one.
  • Pages, colour styles, text styles and components are all saved with the design.

15Exporting

Use Export ▾. The Options section of the menu sets the layout:

  • Responsive (flows): auto-layout frames become flex/grid, widths become fluid and the page is centred. With Treat frames as breakpoints ticked, frames of different widths act as desktop / tablet / mobile versions of the same page and are switched by media queries (up to 767 px and 1023 px).
  • Pixel-perfect: pixel-exact positioning, matching the canvas.

16Theme, context menu and touch

  • Theme: the sun/moon button switches between dark and light editor themes; the choice is remembered.
  • Right-click menu: copy, paste, duplicate, group, auto layout, component actions, order, lock, hide and delete.
  • Touch and tablets: one finger draws or moves, two fingers pan and pinch-zoom. On narrow screens the side panels become drawers opened with the ☰ button.

18Troubleshooting

  • Fonts look different in PNG/SVG: those exports embed Google Fonts, so the browser must be able to reach Google Fonts when you export.
  • Remote images missing from PNG/SVG: images from other websites need to allow cross-origin use; uploaded images always work.
  • Published link does not open for others: /p/<id> lives on the server you are using, so it is only reachable by people who can reach that server.
  • Tailwind / Bootstrap export is unstyled offline: those formats load their framework from a CDN and need internet access.
  • Strokes on polygons: polygons and stars are clipped shapes, so they show fills but not outlines.
  • A change disappeared: use Ctrl+Z; unsaved work is lost on reload, so save regularly.
